Framework-agnostic custom cursor 跨框架自定义光标系统

Custom cursor for
any JS stack 任意 JS 框架的
自定义光标组件

A tiny, dependency-free cursor system for Electron, Tauri, React, Vue, and any other JS+CSS stack. Smooth dot + ring animation with auto state detection. 一个轻量、无依赖的光标系统，适用于 Electron、Tauri、React、Vue 等任何 JS+CSS 技术栈。带平滑跟随动画和自动状态检测。

Quick Start — 3 lines 快速开始 — 3 行代码
Vanilla JS 原生 JavaScript js 
import { MonoCursor } from 'mono-cursor'

// Init once at startup
MonoCursor.init({ color: '#6366f1' })

// Update anywhere — no ref needed
MonoCursor.setColor('#f59e0b')
MonoCursor.disable()      // pause
MonoCursor.enable()       // resume
MonoCursor.destroy()     // cleanup
Script Tag (no build) 直接引入（无需构建） html 
<script src="mono-cursor/dist/index.iife.js"></script>
<script>
  MonoCursor.init({ color: '#6366f1' })
  MonoCursor.setColor('#f59e0b')
</script>
React tsx 
import { MonoCursorProvider } from 'mono-cursor/react'

function App() {
  return (
    <MonoCursorProvider color="#6366f1" ringSize={50}>
      <YourApp />
    </MonoCursorProvider>
  )
}
Data Attributes HTML 数据属性 html 
<a data-cursor="pointer">Link</a>
<div data-cursor="circle">Custom area</div>
<div data-cursor="text">Text mode</div>
All Static API Methods 所有静态 API 方法 js 
MonoCursor.init(options)            // Initialize (call once)
MonoCursor.configure(options)     // Update all options
MonoCursor.enable()              // Resume cursor
MonoCursor.disable()             // Pause cursor
MonoCursor.destroy()             // Remove cursor

// Setters
MonoCursor.setColor('#f00')
MonoCursor.setDotSize(12)
MonoCursor.setRingSize(60)
MonoCursor.setRingBorderWidth(2)
MonoCursor.setLerpFactor(0.08)
MonoCursor.setEnableCircle(false)
MonoCursor.setHideDefaultCursor(false)
MonoCursor.setState('pointer')
